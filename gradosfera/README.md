# Сайт «Градосфера» — ЖК «Новый Квартал»

Статический сайт (HTML/CSS/JS) + `send.php` для заявок. Сборка не нужна — файлы загружаются на хостинг как есть.

## Структура
- `index.html` — главная (лендинг ЖК)
- `privacy.html` — политика конфиденциальности
- `css/style.css`, `js/main.js` — стили и скрипты (планировки и галерея — массивы `PLANS` и `GALLERY` в начале `main.js`)
- `img/` — изображения (webp), `docs/` — PDF-документы
- `send.php` — приём заявок → Telegram и/или e-mail; `config.example.php` — шаблон настроек
- `leads/` — запасной журнал заявок (закрыт от доступа извне)

## Публикация на Timeweb (виртуальный хостинг)
1. Панель Timeweb → «Сайты» → создать сайт, привязать домен `gradosfera.com`
   (DNS домена направить на Timeweb, если он сейчас указывает на другой сервер).
2. Загрузить **содержимое** папки `gradosfera/` в `public_html` сайта (файловый менеджер, FTP или git).
3. Скопировать `config.example.php` → `config.php` прямо на хостинге и заполнить:
   - `telegram_token` — токен бота от @BotFather;
   - `telegram_chat_ids` — id чата/группы менеджеров (бота нужно добавить в группу);
   - и/или `email_to` — почта для заявок.
4. «SSL-сертификаты» → выпустить бесплатный Let's Encrypt и включить перенаправление на HTTPS.
5. Проверить форму: отправить тестовую заявку.

PHP 7.4+ (на Timeweb по умолчанию 8.x), нужен модуль curl (есть на хостинге).

## Локальный просмотр
```
cd gradosfera && php -S localhost:8000
```
