# Сайт ЖК «Новый Квартал» (Градосфера)

Одностраничный статический сайт (HTML/CSS/JS), без сборки и без форм заявок — только телефон и карта.
Анимации прокрутки — GSAP + ScrollTrigger (лежат локально в `js/vendor/`).

## Структура
- `index.html` — вся страница
- `css/style.css` — стили, `js/main.js` — анимации, квартиры (массив `FLATS`), галерея (`GALLERY`)
- `img/photo/` — новые фото дома (утро, закат, двор, фасад, снизу вверх)
- `img/` — остальные рендеры, планировки, логотип; `docs/` — разрешение на строительство (PDF)

## Публикация на Timeweb
1. Создать сайт на виртуальном хостинге, загрузить **содержимое** папки `gradosfera/` в `public_html`.
2. Выпустить бесплатный SSL (Let's Encrypt) и включить перенаправление на HTTPS.
3. Привязать домен `gradosfera.com`: у регистратора домена поменять A-запись на IP хостинга Timeweb.

## Локальный просмотр
```
cd gradosfera && python3 -m http.server 8000
```
