# 3D-модель ЖК «Новый Квартал» для офиса продаж — ЧЕРНОВИК, на сайт не выкладывать

Крутящаяся модель дома: вращение пальцем/мышью, День / Ночь / Облака, нажатие на этаж → квартиры → планировка, цена, рассрочка.
Статика без сборки (three.js r128 лежит в `js/vendor/`). Локально: `cd gk-tour && python3 -m http.server 8822`.

- `js/data.js` — ВСЕ данные: цены, рассрочка, планировки, что на каком этаже (`floorFlats`), габариты дома, файл модели.
- `js/house.js` — дом, собранный по рендерам и планам (пока нет файла архитектора): Г-образный корпус, башня на углу.
- `js/scene.js` — свет, небо, двор, режимы, вращение, зоны нажатия этажей. `js/ui.js` — панель и кнопки.
- Файл архитектора: сохранить как `model/house.glb`, в `data.js` вписать `model.url: 'model/house.glb'` — подменит дом, этажи останутся кликабельными.
- На сайт застройщика не выкладывается: только локальный просмотр.
