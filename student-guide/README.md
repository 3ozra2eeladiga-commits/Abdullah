# Гид для иностранных студентов (первый город — Пятигорск, ПМФИ)

Статический сайт: 3D-карта города (Three.js) + разделы «Квартиры с регистрацией», «Регистрация», «Трамваи», «Праздники», «Первые дни». Языки EN / FR / RU.

- `index.html` — вся страница. Вверху скрипта блок `CITY` (места, квартиры, цвета трамваев) и `T` (тексты на 3 языках), `HOL` — праздники. Telegram для заявок — константа `TG`.
- `data/pyatigorsk.map.json` — карта: здания, дороги, трамвайные маршруты и остановки, парки, рельеф. Собрана из OpenStreetMap + AWS Terrain Tiles (на сайте обязательна подпись «© OpenStreetMap contributors»).
- Новый город = свой `data/<город>.map.json` + свой блок `CITY`.
- Квартиры сейчас — ПРИМЕРЫ (`demo:1`). Настоящие: добавить в `CITY.places` запись с `k:'flat'`, координатами `at:[долгота, широта]`, ценой и убрать `demo`.
- Локально: `python3 -m http.server 8822` в этой папке.
