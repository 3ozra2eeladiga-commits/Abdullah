# HANDOFF — передача дел

## Текущая цель
Довести ИИ-бота цветочного магазина НА.РОМАШКЕ до запуска. Основной канал клиентов —
Telegram @na_romashkee (через Telegram Business), позже Instagram Direct.

## Что сделано (последнее)
- Бот показывает букеты из живого каталога (Пятигорск и Минводы), собирает заказ, шлёт карточку сотрудникам.
- Telegram Business: бот отвечает клиентам в @na_romashkee; если ответил живой сотрудник — бот умолкает.
- Распознаёт кнопку сайта «Купить в TELEGRAM» (ссылка → букет + город) и номер букета (№600).
- Заказ флористу уходит ТОЛЬКО после подтверждения клиента («да»), с актуальными данными.
- Не принимает уже прошедшее время («сегодня к 6:00» днём) — просит актуальное.
- Запрос конкретного цветка (лилии и т.п.) — строго из каталога, без выдумок.
- Правила для похорон/траура (поштучно, красные, чётное количество, прозрачная упаковка/без упаковки).

## Что осталось
- Подключить бота к @na_romashkee: Telegram Premium + Настройки → «Telegram для бизнеса» → «Чат-боты».
- Сверить @username бота, который крутится на сервере.
- Позже: Instagram Direct, голосовые ответы клиенту, распознавание присланных фото.
- Перед реальным запуском сменить ключи/токены, которые светились в переписке.
