# 🌸 Помощник цветочного магазина для Инстаграма

Бот отвечает клиентам в Директе Инстаграма, показывает букеты с фото, оформляет заказ
и присылает его сотрудникам в Telegram. Если не знает ответа — спрашивает сотрудника.

Каталог, цены и наличие бот **сам берёт с сайта магазина** (сейчас: naromashke.ru) и обновляет каждый час.

## Как это устроено

```
Клиент ─► Инстаграм Директ ─► СЕРВЕР (этот код) ─► ИИ (YandexGPT / GigaChat / Claude)
                                     │
                                     └─► Telegram-бот ─► сотрудники (заказы, вопросы)
```

| Файл | Что внутри |
|---|---|
| `shop/shop_info.md` | Правила магазина: адреса, доставка, оплата, стиль общения. **Меняйте здесь обычным текстом.** |
| `bot/catalog.py` | Загрузка каталога с сайта |
| `bot/brain.py` | Инструкция для ИИ и разбор его ответов |
| `bot/instagram.py` | Инстаграм Директ |
| `bot/telegram_bot.py` | Telegram для сотрудников |
| `bot/app.py` | Главный файл, всё соединяет |
| `.env.example` | Образец настроек и ключей |

## Telegram для сотрудников

- Доступ только у людей из списка `TELEGRAM_STAFF_IDS`. Чужим бот не отвечает.
- Узнать свой ID: написать боту `/start`.
- Ответить клиенту: нажать **«Ответить»** на сообщении бота (заказ или вопрос) и написать текст.
- `/pause` (ответом на сообщение) — бот замолкает с этим клиентом. `/resume` — снова отвечает.
- `/test` — проверить бота без Инстаграма: пишете сюда как клиент.
- Если сотрудник сам написал клиенту в Директе — бот молчит с этим клиентом 6 часов.

## Установка на сервер (Ubuntu, сервер за пределами РФ — например Timeweb Cloud, Нидерланды)

1. Подключиться к серверу и выполнить:
   ```bash
   curl -sO https://raw.githubusercontent.com/3ozra2eeladiga-commits/Abdullah/main/deploy/setup.sh && bash setup.sh
   ```
2. Вписать ключи: `nano /opt/flowerbot/.env` (сохранить: Ctrl+O, Enter, выйти: Ctrl+X).
3. Запустить: `systemctl restart flowerbot`
4. Проверить: открыть в браузере адрес сервера — должно быть «Бот работает».
5. Логи: `journalctl -u flowerbot -f`

Обновить до новой версии: `bash /opt/flowerbot/deploy/update.sh`
