УМНАЯ КАМЕРА — проверка на своём компьютере

1. Распакуйте архив (правой кнопкой - «Извлечь всё»).
2. Откройте папку и дважды нажмите:
   «1 Проверка на видео» — программа покажет видео с Кириллом: рамки, тревогу, лицо крупно, голос.
   «2 Проверка на камере ноутбука» — то же самое на камере вашего ноутбука.
   «3 Магазин - внешняя веб-камера с записью» — для магазина: USB веб-камера,
      программа следит и записывает видео в папку records (файлы по 10 минут).
      Эти записи потом пришлите — по ним я донастрою тревоги.
3. Закрыть окно — клавиша Esc.

Если Windows пишет «Система Windows защитила ваш компьютер» —
нажмите «Подробнее», потом «Выполнить в любом случае».

Первый запуск может идти 20–40 секунд — программа загружает нейросеть.
Кадры тревог сохраняются в папку alerts.
