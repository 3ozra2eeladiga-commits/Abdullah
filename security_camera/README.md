# Security камера

Умное наблюдение для продуктового магазина (друг Абдуллы): программа смотрит камеры, обводит людей на экране
и голосом из колонки предупреждает, что идёт наблюдение.

## Версия 1 (24.11.2026) — сделано
- `watch.py` — находит людей на видео (файл, веб-камера или регистратор по RTSP), обводит рамкой с подписью
  «Человек N · под наблюдением», сверху полоса «УМНАЯ КАМЕРА · ЗАПИСЬ» и счётчик «В зале».
- Новый человек → красная плашка «Вы под видеонаблюдением» и голос `voice/welcome.mp3` (ключ `--sound`).
- `make_voice.py` — один раз создаёт голосовые фразы (нужен интернет).
- `demo/` — результат на пробных видео из магазина.

## Запуск на компьютере в магазине
    pip install -r requirements.txt
    python make_voice.py
    python watch.py --source rtsp://ЛОГИН:ПАРОЛЬ@IP_РЕГИСТРАТОРА:554/Streaming/Channels/101 --show --sound
Каналы HiWatch: 101 — камера 1, 201 — камера 2, 301 — камера 3 (последняя цифра 2 = лёгкий поток, напр. 102).

## Что нужно от магазина
- Компьютер или мини-ПК, включённый весь день, в одной сети с регистратором; колонка; экран, видимый покупателям.
- Модель регистратора (наклейка снизу), его логин и пароль, интернет в магазине.
